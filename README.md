# Heart Disease Prediction

## Overview
Machine learning project that predicts the likelihood of heart disease
based on patient-related features.

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## ML Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Prediction

## Models Used
- Logistic Regression
- Naive Bayes
- Decision Tree
- SVM
- KNN

## Evaluation
Accuracy, Precision, Recall, F1-Score, Confusion Matrix
